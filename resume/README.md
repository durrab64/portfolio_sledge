# Resume Folder

Place your resume PDF file in this folder.

**Required filename:** `Muhammad_Durrab_Resume.pdf`

Once you add your resume PDF here, the "Download Resume" button on the portfolio website will automatically trigger the download when clicked.

## Steps:
1. Export your resume as a PDF
2. Rename it to: `Muhammad_Durrab_Resume.pdf`
3. Copy/paste it into this `resume/` folder
4. The download button is already wired up and ready to go!
